# Gravity Sandbox

Playground to try out local models/harnesses. This repo just contains "vibe-coded" gravity
simulation toys that can be viewed in the browser.

* LLM Server: [llama.cpp](https://llama.app)
* Model: [Qwen3.8-27B-GGUF](https://huggingface.co/ggml-org/Qwen3.8-27B-GGUF)
* Agent Harness: [pi](https://pi.dev)
